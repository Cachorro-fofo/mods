# Translations

English lang files for mods that use translation keys. To translate:

1. Copy `en_us.json` from the mod's folder and rename it to your locale code (for example `pt_br.json`, `de_de.json`).
2. Translate the values only. Keep the keys and every `%s` placeholder.
3. Open a pull request adding the file here, or attach it to an issue.

Translations get bundled into the next release of that mod.

| Mod | File | Since |
| --- | --- | --- |
| Levelwise | [levelwise/en_us.json](levelwise/en_us.json) | 1.5.0 |

You can also test a translation in your own game with a resource pack: put the file at `assets/levelwise/lang/<locale>.json`.
